🧮 Python Function Practice – Add Two Numbers

This repository contains basic Python programs to practice functions using simple arithmetic operations like addition, subtraction, and multiplication.

I created this project while learning Python fundamentals, especially how functions work in different ways.

✨ What this project shows

How to create a function in Python

How to pass values to a function

How to take input from the user

How to return values from a function

How to return multiple values from one function

This is useful for Python beginners.

📂 Programs Included
✔ Function with parameters

Values are passed during function call

Function returns the result

✔ Function with user input

Input taken from the user

Output printed in main program

✔ Function without parameters

Input and output handled inside the function

✔ Function returning multiple values

Addition

Subtraction

Multiplication
